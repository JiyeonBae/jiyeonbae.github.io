Development of 3D Reconstruction and Object Recognition Model Based on Single Dataset

Computer Vision · 3D Reconstruction · 2020

Proceedings of the Korea Multimedia Society Summer Conference (KMMS), 2020 · In Korean

Overview

This research presents a unified pipeline for 3D reconstruction and object recognition using a single image dataset. By reusing images captured for 3D reconstruction as training data for object detection, the approach aims to reduce the time and effort required to prepare separate datasets.

Motivation

3D reconstruction and object recognition typically require different data preparation processes, increasing the effort involved in image collection and annotation. Moreover, images collected for reconstruction may require additional labeling and augmentation to support robust object recognition under varying conditions.

Technical Approach

  • Semi-Automated Annotation: Uses SURF feature matching to propagate object bounding boxes across consecutive image frames.
  • Annotation-Aware Data Augmentation: Applies color adjustments, background replacement, occlusion, and geometric transformations, updating bounding-box annotations when necessary.
  • Unified Reconstruction & Recognition: Uses Meshroom for 3D reconstruction and Faster R-CNN for object detection, leveraging a shared image dataset.

My Contributions

As an undergraduate researcher, I developed a semi-automated data preparation pipeline for object recognition, focusing on bounding-box propagation and annotation-aware data augmentation.
