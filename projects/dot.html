Dot. — Time Management Application

UX Design · Mobile Application Development · Mar – May 2022

Overview

Dot. is a time-management application prototype designed to make daily activity tracking less cumbersome. Instead of requiring users to continuously operate timers or manually log activities, it separates quick timestamp recording from later organization, allowing users to document their routines with minimal interruption.

Key Features

  • One-Tap Time Logging: Designed a dot-based interaction for quickly recording activity start and end times without opening the full application.
  • Visual Timeline: Displays recorded timestamps as dots on a daily timeline, allowing users to connect them into activity blocks.
  • Flexible Activity Organization: Lets users add labels and review activities later, separating time capture from detailed documentation.

Implementation

Developed a mobile application prototype using React Native, implementing calendar-based date navigation, timestamp visualization on a daily timeline, and time-data storage.

My Contributions

As part of a two-person team, I contributed to concept development and UX planning through collaborative discussions, focusing primarily on application logic and data handling.
